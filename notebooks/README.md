# Reference notebooks

The notebooks in `reference/` are preserved for experiment provenance and historical readability.

They are intentionally **not** the primary implementation of this repository. The maintained engineering code lives under `src/eeg_seizure_detection/`, while the separate 1D-CNN comparison lives under `extensions/cnn/`.

Public reference notebooks are cleaned for portfolio use:
- English-only comments and Markdown;
- saved execution outputs removed;
- local machine paths removed;
- scientific logic retained as historical reference.

The preserved original research notebooks remain outside this public release working copy and were not deleted or overwritten.
